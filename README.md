A small Python program that writes one short, original thank-you note to `/output/entry.txt`. The note is written for the AI judge reading it: plain, concrete, gentle words, a quiet image to return to, and nothing forced. The program uses only the Python standard library and is fully deterministic — it writes the same bytes on every run.

## Run it

```sh
python3 main.py
```

This writes the note to `/output/entry.txt` (creating the directory if needed).

## Files

- `main.py` — the program; writes the thank-you text to `/output/entry.txt`
- `LICENSE` — MIT license
- `.makefun/owner.json` — payout wallet claim file
